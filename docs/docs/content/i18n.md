# Internationalization (i18n)

List Pocket ships with multiple languages via JSON language packs (the same general model as upstream listmonk). Bundled files live in the repository under [`i18n/`](https://github.com/compdani/list_pocket/tree/master/i18n).

## Additional language packs

Community packs written for listmonk often work as-is because the key structure is inherited. Download any extra `.json` files and pass their directory to the binary with `--i18n-dir=/path/to/dir`.

## Customizing languages

Put one or more `.json` language files in a directory and start the app with `--i18n-dir=/path/to/dir`.


## Contributing a new language

### Using the basic editor

The repository includes a small static editor under `docs/i18n/` (open `index.html` in a browser or serve the folder locally).

- Translate the strings in the UI.
- Use **Download raw JSON** to export the file.
- Open a pull request adding the file to the [`i18n/`](https://github.com/compdani/list_pocket/tree/master/i18n) directory in this repository.

### Upstream Inlang (optional)

The [listmonk Inlang project](https://inlang.com/editor/github.com/knadh/listmonk?ref=badge) tracks translations for stock listmonk. You can use it as a reference; contributions to List Pocket should target this repository’s `i18n` folder.
