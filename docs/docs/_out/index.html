Introduction¶

List Pocket is a self-hosted newsletter and mailing list manager. It keeps the core listmonk-style workflow (campaigns, lists, subscribers, APIs) while running entirely on embedded PocketBase — auth, collections, realtime, and the app’s SQL layer (SQLite under the hood). There is no separate PostgreSQL or other external database server.

The admin UI is a Vue 3 app; the server is a single Go binary.

Developers¶

List Pocket is free and open source software licensed under AGPLv3. See the GitHub repository and the developer setup. The backend is Go; the frontend is Vue with Vuetify.
